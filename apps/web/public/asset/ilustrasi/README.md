# Ilustrasi halaman publik

`klinik-konsultasi-tanpa-wajah-v1.png` adalah ilustrasi AI ruang konsultasi tanpa orang atau wajah, disiapkan sebagai gambar hero bawaan untuk halaman publik klinik. Ukuran 1536 × 1024, PNG dengan latar opak.

Aset ini tidak menggambarkan fasilitas nyata klinik tertentu. Identitas klinik, teks, dan logo ditampilkan terpisah dari gambar agar aset dapat dipakai pada banyak profil klinik. Profil nantinya dapat menggantinya dengan ilustrasi atau foto milik klinik.

`klinik-dokter-pasien-berhijab-v1.png` adalah alternatif hero yang menampilkan dokter perempuan dan pasien perempuan berhijab, keduanya tanpa detail wajah. Ukuran 1536 × 1024, PNG dengan latar opak bernuansa teal, sage, dan krem. Tokoh bersifat ilustratif dan tidak mewakili staf atau pasien nyata. Prompt sumber: `output/desain-halaman-publik/ilustrasi-dokter-pasien-berhijab-prompt-v1.txt`.

Dibuat menggunakan tool imagegen bawaan. Prompt sumber tersimpan di `output/desain-halaman-publik/ilustrasi-hero-prompt-v1.txt`. Aset belum dipasang ke halaman aplikasi.
