# Lembar Pengesahan SOP Pelindungan Data Pribadi

Nomor: PENG/PDP/01/XI/2026

Pimpinan Klinik Bhakti Rahayu (PT BHAKTI RAHAYU MEDIKA) mengesahkan dan memberlakukan prosedur berikut untuk seluruh petugas klinik, sejak tanggal ditetapkan:

| No | Nomor | Judul |
|---|---|---|
| 1 | SOP/PDP/02/XI/2026 | SOP Permintaan Hak Pemilik Data dan Kanal Aduan |
| 2 | SOP/PDP/03/XI/2026 | SOP Penanganan Insiden Kebocoran atau Kegagalan Pelindungan Data |
| 3 | SOP/PDP/04/XI/2026 | SOP Retensi dan Pemusnahan Data Pribadi |
| 4 | SOP/PDP/05/XI/2026 | SOP Permintaan Data oleh Aparat Penegak Hukum dan Pihak Berwenang |
| 5 | SOP/PDP/06/XI/2026 | Program Sosialisasi dan Pelatihan Pelindungan Data Pribadi |

Prosedur ini dilaksanakan dan dipantau oleh Pejabat Pelindungan Data Pribadi (Yudi Saeful Rizal, Tim IT) dan ditinjau sekurang-kurangnya setahun sekali.
